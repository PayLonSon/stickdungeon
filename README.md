# 火柴人地城 StickDungeon

火柴人風格、回合制、2–4 人連線合作的地城冒險網頁遊戲。用手機瀏覽器輸入房號就能和朋友一起玩，不用安裝 App。

> 🚧 開發中。目前只有規格書，遊戲尚未完成。

- 規格書：[SPEC.md](SPEC.md)
- 部署：GitHub Pages（純靜態網站）

## 注意

連線採 P2P（WebRTC），同房玩家可得知彼此的 IP 位址，請只和認識的人同房。
